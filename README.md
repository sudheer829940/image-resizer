# 🖼️ Image Resizer Tool

A simple **Image Resizer Tool** made with **HTML, CSS, and JavaScript**.  
Upload any image, set custom width & height, resize it, and download the resized image instantly.  

---

## 🚀 Live Demo
👉 [Click here to try the tool](https://YOUR-USERNAME.github.io/image-resizer/)

---

## 📌 Features
- Upload an image from your device  
- Enter custom width & height (in pixels)  
- Preview resized image on canvas  
- Download the resized image as PNG  

---

## 📂 How to Run Locally
1. Clone this repository or download the code.  
2. Open `index.html` in any browser.  
3. Upload → Enter width & height → Resize → Download.  

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**
