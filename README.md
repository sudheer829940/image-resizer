# 🖼️ Image Resizer Tool

Ye ek simple **Image Resizer Tool** hai jo **HTML, CSS, aur JavaScript** ka istemal karta hai.  
Tum apni image upload kar sakte ho, width aur height set kar sakte ho, aur fir image resize kar ke download kar sakte ho.

---

## 🚀 Live Demo
👉 (https://sudheer829940.github.io/image-resizer)  

---

## 📌 Features
- Image upload kar sakte ho  
- Custom **width** & **height** enter kar sakte ho (pixels me)  
- Canvas pe resized image dekh sakte ho  
- Resized image **PNG** format me download kar sakte ho  

---

## 📂 How to Run Localy
1. Repository clone karo ya code download karo.  
2. `index.html` browser me open karo.  
3. Image upload karo → width & height enter karo → **Resize** button dabao → resized image download karo.  

---

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript (plain / vanilla JS)
